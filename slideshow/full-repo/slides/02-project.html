IDEIA CENTRAL

Estatísticas reais parametrizam uma simulação explicável: cada posse combina decisões do engine e sorteios probabilísticos.

ESTADO ATUAL

Os módulos principais existem, mas a interface, a API e a simulação ainda não estão conectadas em um fluxo único.

Este percurso representa o produto pretendido, não um fluxo já integrado. O catálogo é produzido pela ingestão e pode alimentar o seed do banco ou o demo independente do engine. O backend de sessões e a interface existem separadamente; a transmissão mostrada hoje usa dados mock.
