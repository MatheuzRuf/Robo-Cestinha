Introdução

O projeto simula uma partida de basquete. Heurísticas definem as ações dos jogadores e geram eventos, como passes, arremessos e cestas, que aparecem na interface.

A ideia é simular uma partida de basquete usando heurísticas para determinar ações e gerar eventos. A interface mostrada aqui ainda usa dados mock e não está conectada ao motor de simulação.
