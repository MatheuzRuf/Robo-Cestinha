Separação por responsabilidade: páginas organizam seus componentes próprios, reutilizam a base compartilhada e recebem e pedem dados pelos services.
A interface é composta em três grupos: páginas, componentes privados por página e componentes compartilhados. O App direciona para Home, Bracket Tree, MatchBroadcast ou BracketTeam; as páginas compõem os elementos específicos de cada fluxo e também usam a base compartilhada. Os services de Session, Player, Team, Match e Bracket concentram as operações do domínio. Eles se comunicam com a API por REST e recebem os eventos da transmissão por SSE; os dados e ações alimentam os componentes da interface.
