A API da NBA publica apenas três grupos de posição — guarda, ala e pivô. A taxonomia clássica de cinco posições vem do Basketball-Reference, mas a página fica atrás do Cloudflare e não pode ser coletada por script; o único trabalho manual é salvá-la uma vez no navegador. A partir daí a pipeline analisa o HTML com um parser da biblioteca padrão, extrai a posição primária de cada jogador e guarda em JSON para os reprocessamentos. A junção com os jogadores da API é feita por nome normalizado: sufixos entre parênteses e geracionais são removidos, iniciais e acentos são colapsados, e três aliases manuais resolvem variações de apelido. O relatório de qualidade confirma que nenhum dos 582 jogadores ficou sem posição clássica.
