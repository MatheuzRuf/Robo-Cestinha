O coordenador orquestra a partida, o engine gera eventos e frames, e a API entrega tudo para a interface.
Esta é a cadeia que o projeto está montando. O frontend envia comandos e recebe o resultado da API; a API aciona um coordenador que executa o engine; o engine produz eventos e frames; a narração enriquece cada evento; e a API devolve tudo ao frontend. A integração avança em etapas, mantendo cada peça demonstrável enquanto a seguinte é construída.
